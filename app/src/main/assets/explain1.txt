###0001
【方法】哈希表一次遍历。
【要点】
1. 暴力双重循环是 O(n^2)，瓶颈在于"找 target-x"太慢。
2. 用哈希表把"数值 -> 下标"缓存起来，查找 target-x 只需 O(1)。
3. 边遍历边查询：查询的是"当前数之前出现过的数"，所以同一元素不会被使用两次，也不需要担心漏解。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】必须先查询再插入当前数；若 target=2x 且 x 只出现一次，先插入会误用同一个元素。

###0049
【方法】排序作键 + 哈希分组。
【要点】
1. 两个单词是异位词，当且仅当排序后的字符串完全相同（"eat"/"tea" -> "aet"）。
2. 把排序结果当作分组 key，一次扫描即可完成分组。
3. 进阶写法：统计 26 个字母的出现次数，把计数数组拼成字符串作 key，避免 O(k log k) 排序。
【复杂度】时间 O(n·k·log k)，空间 O(n·k)；n 为单词数，k 为平均长度。
【易错点】computeIfAbsent 里新建的列表要返回去（key 不存在时）。

###0128
【方法】哈希集合 + 序列起点检测。
【要点】
1. 直接排序是 O(n log n)，不满足题目要求的 O(n)。
2. 把所有数放进 HashSet；对每个数 x，若 x-1 存在，说明 x 是某段连续序列的中间部分，跳过。
3. 只有当 x-1 不存在时，x 才是某个连续序列的起点，从 x 开始向后数到断开处。
4. 由于每个数只会在"自己所在序列的起点"被展开一次，总工作量为 O(n)。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】要遍历 HashSet 而不是原数组，否则重复元素会导致重复展开。

###0283
【方法】快慢双指针（原地分区）。
【要点】
1. 维护不变量：[0, slow) 全是非零元素且保持原相对顺序。
2. fast 扫描整个数组，遇到非零元素就与 slow 位置交换，然后 slow 右移。
3. 扫描结束后 [slow, n) 自动全是 0，且交换次数等于非零元素个数。
4. 变体：先把非零元素前移再补零，写操作次数更少。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】交换后 slow 必须 +1，否则不变量被破坏。

###0011
【方法】对撞双指针 + 贪心。
【要点】
1. 容量 = 宽度 × min(两边高度)。从最大宽度开始，之后宽度只会减小，必须靠高度提升来弥补。
2. 移动较高的一侧毫无意义：新面积的高仍受限于较矮的一侧，而宽更小，面积必然更小。
3. 所以每次移动较矮的一侧，保留一切可能更优的局面。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】不要写错移动条件——比较的是 height[left] 与 height[right]。

###0015
【方法】排序 + 枚举第一个数 + 双指针。
【要点】
1. 排序后固定 i，问题转化为"在 i 右侧找两数之和 = -nums[i]"，用对撞指针 O(n) 解决。
2. 三重去重：i 与前一个相同跳过；找到解后 left、right 也要跳过重复值。
3. 剪枝：若 nums[i] + 最小的两个数 > 0，后面不可能有解，直接 break。
【复杂度】时间 O(n^2)，空间 O(log n)。
【易错点】找到一组解后 left 和 right 都要继续移动，否则死循环。

###0042
【方法】双指针（也可用前后缀最大值数组或单调栈）。
【要点】
1. 位置 i 能接的水 = min(左侧最高, 右侧最高) - height[i]。
2. 关键观察：若 leftMax < rightMax，则位置 left 的水位只由 leftMax 决定（右边必然够高），可以立即结算，无需知道精确的右侧最高值。
3. 因此维护两个指针从两端向内、两个 running max，哪边 max 小就结算哪边。
4. 单调栈解法：栈内柱子递减，遇到更高柱时逐层横向结算，每层水 = 宽 × 层高。
【复杂度】时间 O(n)，空间 O(1)（双指针）/ O(n)（栈）。
【易错点】结算用的是"当前一侧的 max"减当前高度，别用对侧。

###0003
【方法】滑动窗口。
【要点】
1. 窗口 [left, right] 内不含重复字符，right 不断右扩。
2. 遇到重复字符时，left 必须右移到把重复字符移出窗口为止——窗口收缩的单调性保证每个字符最多进出各一次。
3. 每次扩张后用 right - left + 1 更新答案。
4. 优化：用 HashMap 记录字符最后位置，重复时 left 直接跳到 max(left, last[c]+1)，无需逐格收缩。
【复杂度】时间 O(n)，空间 O(字符集大小)。
【易错点】while 收缩时别忘了先移除 left 处的字符再 left++。

###0438
【方法】定长滑动窗口 + 计数数组。
【要点】
1. 异位词的窗口长度固定为 p.length()，用两个 26 长度数组分别统计 p 与当前窗口。
2. 窗口右移 = 右端字符 +1、左端字符 -1，O(1) 更新。
3. 每步比较两数组是否相等（26 次比较，可视为常数；也可用 diff 变量降到真 O(1)）。
【复杂度】时间 O(n)，空间 O(1)（26 数组）。
【易错点】别忘了检查第一个窗口本身；右移时先加后减或先减后加都可以，但下标别写错。

###0560
【方法】前缀和 + 哈希表。
【要点】
1. 子数组 nums[j..i] 的和 = pre[i] - pre[j-1]，等于 k 等价于 pre[j-1] = pre[i] - k。
2. 边扫边用哈希表记录每个前缀和出现的次数，答案累加 map.get(pre - k)。
3. 初始 map 放入 {0: 1}，表示"从下标 0 开始的子数组"也要被统计到。
4. 顺序很重要：先查询再存入当前前缀和，否则 k=0 时会把空子数组算进去。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】这题元素有负数，不能用滑动窗口（窗口和没有单调性）。

###0239
【方法】单调队列（双端队列，存下标，值单调递减）。
【要点】
1. 队列保存"还可能成为窗口最大值的下标"，从队头到队尾对应的值严格递减。
2. 新元素入队前，把队尾所有 ≤ 它的值弹出——这些值比它小又比它先过期，永远不可能再成为答案。
3. 队头下标滑出窗口范围（<= i-k）时从队头弹出。
4. 窗口成形后（i ≥ k-1），队头就是当前窗口最大值。
【复杂度】时间 O(n)（每个下标最多入队/出队一次），空间 O(k)。
【易错点】判断过期用的是"队头下标 ≤ i-k"；弹出队尾用 while 不是 if。

###0076
【方法】滑动窗口 + need/window 计数。
【要点】
1. need 记录 t 中每个字符的需求量；window 记录窗口内各字符数量；valid 记录"数量已达标"的字符种类数。
2. right 扩张：某字符数量第一次达到 need 时 valid++。
3. valid == need.size() 说明窗口已覆盖 t，开始收缩 left：每次收缩前更新答案，移出字符若导致某类数量跌回需求以下则 valid--。
4. 收缩到刚好不满足为止，继续扩张，保证 O(n)。
【复杂度】时间 O(|s| + |t|)，空间 O(字符集)。
【易错点】比较 Integer 计数要用 equals 或 intValue()，直接 == 会比较对象引用。

###0053
【方法】Kadane 算法（一维 DP）。
【要点】
1. 定义 f(i) = 以 nums[i] 结尾的最大子数组和。
2. 转移：f(i) = max(nums[i], f(i-1) + nums[i])——前面的和是正贡献就接上，否则另起一段。
3. 答案是所有 f(i) 的最大值，扫描时同步维护即可。
4. 代码里 cur 即 f(i)，滚动为 O(1) 空间。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】best 初始值要用 Integer.MIN_VALUE 而不是 0（数组可能全负）。

###0056
【方法】排序 + 线性合并。
【要点】
1. 按左端点排序后，重叠的区间必然相邻，可以一次扫描合并。
2. 若当前区间左端点 ≤ 已合并最后一个区间的右端点，则重叠，扩展右端点为二者较大值（当前区间可能被完全包含）。
3. 否则新开一段。
【复杂度】时间 O(n log n)（排序主导），空间 O(log n)。
【易错点】扩展右端点时要取 max(lastEnd, curEnd)，不是直接覆盖。

###0189
【方法】三次翻转（环形旋转的技巧）。
【要点】
1. 向右轮转 k 位 = 后 k 个元素整体搬到前面。
2. 先整体翻转，再翻转前 k 个、翻转后 n-k 个，即得结果，空间 O(1)。
3. k 要先对 n 取模（k 可能大于 n）。
4. 另两种经典解法：额外数组 answer[(i+k)%n]=nums[i]；或循环替换（从 0 出发按 gcd(n,k) 组轮转）。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】k %= n 不能漏；三次翻转的区间边界容易写错。

###0238
【方法】前后缀乘积。
【要点】
1. answer[i] = (nums[0..i-1] 的乘积) × (nums[i+1..n-1] 的乘积)。
2. 先从左到右把前缀乘积写进 answer；再用一个滚动变量 suffix 从右往左乘上后缀乘积。
3. 不允许用除法是因为数组可能含 0，除法需要特判且不符合题意。
【复杂度】时间 O(n)，空间 O(1)（输出数组不计入）。
【易错点】第一遍 answer[0] = 1（左边没有元素）；第二遍 suffix 初值为 1。

###0041
【方法】原地哈希（置换归位）。
【要点】
1. 答案只可能是 [1, n+1]：若 1..n 都在，答案 n+1；否则答案是最小的缺席正数。
2. 目标状态：值 x 放到下标 x-1。交换直到当前格子的值不在 [1,n] 或已归位。
3. 交换条件里用 nums[nums[i]-1] != nums[i] 防止重复元素导致死循环。
4. 归位后第一个 nums[i] != i+1 的下标 i，答案即 i+1。
【复杂度】时间 O(n)（每个值最多交换一次就归位），空间 O(1)。
【易错点】while 循环里的交换要小心下标顺序，避免 nums[i] 被先改掉。

###0073
【方法】首行首列作标记（O(1) 空间）。
【要点】
1. 直接方案：记录含 0 的行/列集合，O(m+n) 空间。
2. 省空间技巧：用第一行、第一列充当标记数组——matrix[i][0]=0 表示第 i 行要清零，matrix[0][j]=0 表示第 j 列要清零。
3. 因为第一行第一列本身可能含 0，要先用两个布尔变量单独记录它们是否需要清零。
4. 处理顺序：打标记 -> 清内部 -> 清第一行 -> 清第一列。
【复杂度】时间 O(mn)，空间 O(1)。
【易错点】最后处理第一行/列时要用预先保存的布尔值，不能看标记（标记已被覆盖）。

###0054
【方法】边界收缩模拟。
【要点】
1. 维护 top/bottom/left/right 四个边界，循环按"右→下→左→上"四个方向走一圈。
2. 每走完一圈边界向内收缩一格。
3. 关键陷阱：当只剩一行或一列时，四个方向的循环会重复遍历。处理办法：走"下→左"前判断 top < bottom，走"左→上"前判断 left < right。
【复杂度】时间 O(mn)，空间 O(1)。
【易错点】右列向下从 top+1 开始（top 已走），左列向上终点是 top+1（top 位置已走）。

###0048
【方法】转置 + 行翻转。
【要点】
1. 顺时针旋转 90° 的数学分解：先转置（沿主对角线翻转），再每行左右翻转。
2. 转置时只遍历上三角（j > i），否则交换两次等于没换。
3. 行翻转即首尾对称交换。
【复杂度】时间 O(n²)，空间 O(1)。
【易错点】转置的双层循环 j 从 i+1 开始；若要逆时针旋转则是转置 + 上下翻转。

###0240
【方法】右上角出发的"排除式"搜索（ staircase / 阶梯搜索）。
【要点】
1. 从右上角看：左边更小，下面更大——恰好像二叉搜索树。
2. 当前值 > target：该列下方的值更大，整列排除，左移一列。
3. 当前值 < target：该行左边的值更小，整行排除，下移一行。
4. 每步排除一行或一列，最多 m+n-1 步。
【复杂度】时间 O(m+n)，空间 O(1)。
【易错点】左下角出发也可以，但普通二分会失效（该矩阵整体不满足"Z 字形有序"）。

###0160
【方法】双指针等长切换（浪漫相遇法）。
【要点】
1. 设 A 独有长度 a、B 独有长度 b、公共部分 c。
2. pA 走 a+c 后从 B 头开始再走 b；pB 走 b+c 后从 A 头开始再走 a——两者都走了 a+b+c 步。
3. 若相交，最后 c 段相同，二者必在交点相遇；若不相交，二者同时走到 null（也是相等），退出循环返回 null。
【复杂度】时间 O(m+n)，空间 O(1)。
【易错点】切换时赋 headB/headA 而不是 null.next；不用考虑长度差，公式自动消化。

###0206
【方法】迭代三指针 / 递归。
【要点】
1. 迭代：prev=null 起步，每次保存 next，断开重连 cur.next=prev，然后 prev=cur、cur=next。
2. 循环结束时 cur=null，prev 就是新头。
3. 递归：reverse(head) 先递归到尾，回溯时 head.next.next=head，head.next=null，返回新头。递归写法空间 O(n)。
【复杂度】时间 O(n)，迭代空间 O(1)。
【易错点】迭代中必须先存 next 再改 cur.next，否则链断裂。

###0234
【方法】找中点 + 反转后半段 + 比较。
【要点】
1. O(n) 空间解法：复制到数组双指针比较。进阶要求 O(1) 空间：
2. 快慢指针（fast 每次两步）找到中点；反转后半段；前半段与反转后的后半段逐节点比较。
3. 奇偶长度都适用：比较循环以 p2（较短的一侧）为准。
4. 严谨做法最后还应还原链表（面试加分项）。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】找中点时 fast 要先判断 fast.next 与 fast.next.next，避免空指针。

###0141
【方法】Floyd 快慢指针。
【要点】
1. 慢指针一步、快指针两步。若有环，二者进入环后相对速度为 1，必然相遇（追及问题）。
2. 无环则 fast 或 fast.next 先到 null。
3. 相等判断放在走完一步之后。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】循环条件 fast != null && fast.next != null，两个都要判。

###0142
【方法】Floyd 判圈两阶段。
【要点】
1. 阶段一：快慢指针在环内相遇（同上一题）。
2. 阶段二：数学推导——头到入环口 a 步，入环口到相遇点 b 步，环长 c；相遇时慢指针走 a+b，快指针走 a+b+kc，由 2(a+b)=a+b+kc 得 a=(k-1)c+(c-b)。
3. 因此一个指针回到头部，二者同速前进，再相遇处即入环口。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】阶段二两个指针必须同速；无环时在阶段一循环里直接返回 null。

###0021
【方法】哑节点 + 归并式拼接。
【要点】
1. dummy 节点免去"新头"的特判。
2. 每次比较两链当前头，较小者接到结果尾部并后移。
3. 一链耗尽后，把另一链剩余整体接上（剩余部分本身有序）。
【复杂度】时间 O(m+n)，空间 O(1)。
【易错点】最后是 cur.next = l1 != null ? l1 : l2，不是逐个拼接。

###0002
【方法】模拟竖式加法。
【要点】
1. 链表已是逆序存储，从前往后恰好是"个位→高位"，天然匹配加法顺序。
2. 三循环条件：l1 != null || l2 != null || carry != 0——carry 残留也要生成新节点。
3. 每位：sum = carry + 两链当前值（空链补 0），新节点存 sum%10，进位 sum/10。
【复杂度】时间 O(max(m,n))，空间 O(1)（输出不计）。
【易错点】循环结束后漏了 carry 会导致 [5] + [5] 输出 [0] 而不是 [1,0]。

###0019
【方法】哑节点 + 快慢指针一趟扫描。
【要点】
1. 要删除倒数第 n 个，需要定位倒数第 n+1 个（前驱）。
2. fast 先走 n+1 步，然后 fast/slow 同速；fast 变 null 时 slow 恰好停在前驱。
3. dummy 头节点统一处理"删除的是头节点"的情形。
4. 对比：先求长度再二次遍历也可以，但本题进阶要求一趟扫描。
【复杂度】时间 O(L)，空间 O(1)。
【易错点】fast 先走的是 n+1 步（含 dummy 那一格）；删除操作 slow.next = slow.next.next。

###0024
【方法】哑节点 + 局部两两交换。
【要点】
1. prev 指向已处理段的尾节点；每次交换 prev 后面的两个节点 a、b。
2. 交换三步：a.next = b.next；b.next = a；prev.next = b。
3. 交换后 a 成为该对的后一个，prev 移到 a。
4. 循环条件：prev.next 和 prev.next.next 都存在。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】三步的顺序不能乱，先保存 b.next；否则节点丢失。

###0025
【方法】分组反转。
【要点】
1. 每组先检查是否满 k 个（从 prevGroup 走 k 步），不满则保持原序结束。
2. 组内反转时，反转的"尾"指向下一组开头（prev 初始化为 nextGroup）。
3. 反转完成后：prevGroup.next = 新组头（原组尾 end），prevGroup 更新为原组头（反转后是组尾）。
4. 与 206 的区别仅在于：反转区间的边界和前后连接要精确。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】prev 初始化为下一组开头而不是 null；别忘了 prevGroup 的更新。

###0138
【方法】哈希映射 / 节点插入法。
【要点】
1. 难点在于 random 指向的节点可能还没创建。
2. 哈希法：第一遍为每个原节点创建拷贝并存 map；第二遍通过 map 把 next/random 都连到"新节点"上。
3. 进阶 O(1) 空间：把每个拷贝节点插到原节点后面（1->1'->2->2'），然后 copy.random = cur.random.next，最后拆链。
【复杂度】哈希法时间 O(n)、空间 O(n)；插入法时间 O(n)、空间 O(1)。
【易错点】第二遍连接时 map.get(null) 返回 null，恰好天然正确。

###0148
【方法】归并排序（链表版）。
【要点】
1. 快慢指针找中点：fast 从 head.next 出发，slow 停在前半段末尾，从 slow.next 断开。
2. 递归排序两半，再套用"合并两个有序链表"。
3. 这是链表排序的标准解法：数组快排在链表上没有随机访问优势。
4. 进阶 O(1) 空间要用自底向上归并（按步长 1,2,4... 分组合并）。
【复杂度】时间 O(n log n)，空间 O(log n)（递归栈）。
【易错点】断链 slow.next = null 不能漏；fast 起点设 head.next 保证偶数长度时切分均衡。

###0023
【方法】分治两两合并。
【要点】
1. 逐个往结果里塞是 O(nk)；分治像归并一样两两合并，每层工作量 O(n)，共 log k 层。
2. mergeRange 递归到单条链返回，两两调用"合并两个有序链表"。
3. 另解：小根堆维护 k 个当前头节点，每次弹出最小并补充其后继，O(n log k)。
【复杂度】时间 O(n log k)，空间 O(log k)（递归栈）。
【易错点】空数组、空链表要处理；递归边界 left == right 直接返回该链。

###0146
【方法】哈希表 + 双向链表。
【要点】
1. 需求拆解：get/put 都要 O(1)——哈希表负责 O(1) 定位，双向链表负责 O(1) 的"移到头部/删除尾部"。
2. 链表顺序即使用顺序：head 侧最近使用，tail 侧最久未用。
3. get：查到后节点移到头部。put：已存在则更新+移头；不存在且满了则删 tail.prev 并从 map 移除，再头插新节点。
4. 哑头哑尾让所有插入删除都不需要判空。
【复杂度】get/put 均 O(1)，空间 O(capacity)。
【易错点】moveToHead = remove + add，两步都要写全，prev/next 四根指针别接错。

###0094
【方法】显式栈迭代。
【要点】
1. 中序 = 左 → 根 → 右。迭代的核心是"一路向左压栈，弹出即访问，再转向右子树"。
2. 外层循环条件 cur != null || 栈非空：右子树为空时还要回去弹上层节点。
3. 递归写法两行，但进阶要求掌握迭代。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】访问后 cur = cur.right 而不是 cur = stack.pop()。

###0104
【方法】递归后序统计。
【要点】
1. 空树深度 0；否则 max(左深, 右深) + 1。
2. 也可 BFS 层序数层数，结果相同。
【复杂度】时间 O(n)，空间 O(h)（最坏 O(n) 链状树）。
【易错点】深度按节点数计（本题定义），边数则要减 1。

###0226
【方法】递归交换。
【要点】
1. 对每个节点：先递归翻转左右子树，再交换自己的左右指针。
2. 必须先保存递归结果再交换，否则引用被覆盖。
3. 也可以先交换再递归，两种顺序都正确。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】常见笔误：交换时用了未保存的 root.left 递归结果。

###0101
【方法】递归比较镜像对。
【要点】
1. 树对称 <=> 左子树与右子树互为镜像。
2. 镜像判断：两根值相等，且 (a.left, b.right) 镜像、(a.right, b.left) 镜像。
3. 空与空的组合是 true，一空一非空是 false。
4. 迭代版用队列成对入队（a.left/b.right、a.right/b.left）实现同样逻辑。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】递归参数是"交叉的"四组比较，别写成同侧比较。

###0543
【方法】后序遍历 + 全局最大值。
【要点】
1. 直径 = 任意两节点路径的边数最大值，路径必在某节点"拐弯"。
2. 定义 f(node) = 从 node 向下的最大深度；经过 node 的直径候选 = 左深 + 右深。
3. 递归返回深度，同时用全局变量记录 max(left+right)。
4. 注意直径可能不经过根，所以必须全局记录而不是返回值。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】返回给父节点的是 max(left,right)+1，不能把左右相加返回。

###0102
【方法】BFS 分层。
【要点】
1. 队列里一次存一整层，size 固定后循环 size 次，弹出的就是该层所有节点。
2. 每层收集为一个子列表，子节点进入下一层。
3. 这是所有"层"字辈问题（右视图、之字形、每层最大值）的模板。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】size 要在 for 循环前取，循环中队列长度是变化的。

###0108
【方法】中点递归构建。
【要点】
1. 要高度平衡，左右子树节点数要尽量均分：取中点作根。
2. 左半区间递归建左子树，右半区间建右子树。
3. 有序数组 + 中点建树，中序恰好还是升序，故是合法 BST。
【复杂度】时间 O(n)，空间 O(log n)（递归栈，输出树不计）。
【易错点】mid 划分区间 [left, mid-1] 与 [mid+1, right]，mid 本身成为根不再参与。

###0098
【方法】上下界递归（或中序递增检查）。
【要点】
1. BST 性质是"整棵子树"的约束，不只是父子节点——常见错误是只比较直接子节点。
2. 递归带上 (lower, upper)：左子树上界收紧为当前值，右子树下界收紧为当前值。
3. 用 long 传边界，防止 int 最小/最大值本身作为节点值时比较失败。
4. 等价解法：中序遍历序列必须严格递增，维护 prev 值逐个比较。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】边界是开区间：等于 lower/upper 也算非法。

###0230
【方法】迭代中序，第 k 次弹出即答案。
【要点】
1. BST 中序遍历递增，第 k 个被访问的节点就是第 k 小。
2. 用迭代而非全量递归，可以在第 k 个时提前返回。
3. 模板与 94 相同：向左压栈 → 弹出访问（k--）→ 转右。
【复杂度】时间 O(H + k)，空间 O(H)。
【易错点】k 是引用语义的计数，找到后直接 return，别继续遍历。

###0199
【方法】BFS 层序取末位（或 DFS 根右左）。
【要点】
1. 从右侧看 = 每层最后一个节点。
2. BFS：每层循环 size 次，i == size-1 时收集。
3. DFS 另解：按 根→右→左 遍历，每个深度第一次到达的节点入结果（结果列表长度即当前最大深度）。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】BFS 中 left/right 入队顺序无关紧要（取的是位置不是方向），DFS 中则必须先右后左。

###0114
【方法】前驱节点拼接（Morris 式，O(1) 空间）。
【要点】
1. 展开为先序单链：每个节点的"先序后继"在左子树的最右下角。
2. 对每个有左子树的节点：找到左子树最右节点（前驱），把当前右子树接到前驱.right；再把左子树整体搬到右侧，left 置 null。
3. cur 沿 right 指针推进，全程只改指针。
4. 直观版：先序遍历存列表再逐个重连，空间 O(n)。
【复杂度】时间 O(n)（每个前驱查找摊还常数），空间 O(1)。
【易错点】先接前驱.right = cur.right，再搬左子树，顺序反了会丢右子树。

###0105
【方法】前序定位根 + 中序分割 + 哈希加速。
【要点】
1. 前序第一个元素是根；在中序里找到它，左边是左子树、右边是右子树。
2. 用 HashMap 存中序 值→下标，查找 O(1)。
3. 递归时前序用全局 preIdx 顺序推进——必须先递归左子树再递归右子树（前序顺序）。
4. 中序区间 [l, r] 为空时返回 null。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】递归左右顺序反了，preIdx 会错位；区间长度用中序划分而不是前序。

###0437
【方法】前缀和 + 哈希 + 回溯（树上版 560 题）。
【要点】
1. 根到当前节点的路径是链式前缀和；一条路径和为 target 等价于 pre_i - pre_j = target。
2. 哈希表统计"当前根到节点路径上"各前缀和出现次数，进入节点时查 pre - target。
3. 离开子树时要回溯（当前前缀和计数 -1），否则兄弟子树会查到不相干路径。
4. 初始放入 {0:1} 支持从根开始的路径。
【复杂度】时间 O(n)，空间 O(n)。和可能溢出 int，用 long。
【易错点】回溯撤销与 560 的"先查再存"一样关键。

###0236
【方法】后序递归。
【要点】
1. 递归定义：在子树中找 p 或 q；找到返回节点引用，找不到返回 null。
2. 当前节点等于 p 或 q 时直接返回自身（祖先可以是自己）。
3. 左右递归结果都非空 => p、q 分居两侧，当前节点是最近公共祖先。
4. 只有一侧非空 => 答案就是那一侧的返回值。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】不要在找到 p/q 后继续深挖；返回的引用本身就是答案路径。

###0124
【方法】树形 DP（后序）。
【要点】
1. 两条信息要分开：向父节点汇报的是"单侧下探最大和"，全局答案才是"经过当前节点拐弯的和"。
2. f(node) = val + max(0, f左, f右)：负贡献直接舍弃（取 0）。
3. 拐弯候选 = val + max(0,f左) + max(0,f右)，用全局变量维护最大值。
4. 与 543 结构完全相同，只是"深度"换成了"带权路径和"。
【复杂度】时间 O(n)，空间 O(h)。
【易错点】返回值必须是 val + max(left, right)，不能返回拐弯和；全局初始值用 MIN_VALUE（节点值可能全负）。
