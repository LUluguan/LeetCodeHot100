###0200
【方法】DFS 沉岛（也可 BFS / 并查集）。
【要点】
1. 岛屿 = 上下左右连通的 '1' 连通块。遍历网格，每遇到一个未访问的 '1'，计数 +1。
2. 然后从该点 DFS，把整个连通块的 '1' 都改成 '0'（"沉岛"），保证每个岛屿只被统计一次。
3. 沉岛操作同时承担了 visited 标记，无需额外数组。
【复杂度】时间 O(mn)，空间 O(mn)（最坏全陆地时递归深度）。
【易错点】DFS 入口先判越界和当前值；递归四方向写全。

###0994
【方法】多源 BFS。
【要点】
1. 不同于普通 BFS 的单起点：所有腐烂橘子在第 0 分钟同时入队，作为多个起点同时扩散。
2. 统计新鲜橘子总数 fresh；每扩散一层 minutes+1，被感染的新鲜橘子减一。
3. 结束后 fresh == 0 返回 minutes，否则有永远烂不掉的橘子返回 -1。
4. 边界技巧：fresh==0 时直接返回 0。
【复杂度】时间 O(mn)，空间 O(mn)。
【易错点】minutes 应该在"这一层确实感染了新橘子"时才递增，或用 fresh>0 作循环条件。

###0207
【方法】拓扑排序（Kahn / BFS）。
【要点】
1. 课程依赖构成有向图，能修完所有课 <=> 图无环 <=> 存在拓扑序。
2. 统计每门课入度（先修课数量），入度 0 的先入队。

4. 最终出队次数 == 课程总数则 true。
【复杂度】时间 O(V + E)，空间 O(V + E)。
【易错点】边方向：prerequisites=[a,b] 表示 b→a（学完 b 才能学 a），别建反。

###0208
【方法】26 叉前缀树。
【要点】
1. 每个节点 26 个子指针 + isEnd 标志。字符串沿字符逐层下沉，路径即前缀。
2. insert：路径缺失就新建，末节点 isEnd=true。
3. search：沿路径走到底后还要求 isEnd（必须完整单词）；startsWith 只要求路径存在。
4. 公共工具 find(s) 返回终点节点或 null，两个查询复用。
【复杂度】每次操作 O(L)；空间 O(总字符数 × 26)。
【易错点】search 与 startsWith 的区别就在 isEnd 这个标志位。

###0046
【方法】回溯 + used 数组。
【要点】
1. 排列与组合的区别：排列关心顺序，每层可以从任意未使用位置选，所以需要 used 标记而不是 start 下标。
2. path 长度达到 n 时收集答案（必须拷贝，path 是复用对象）。

###0078
【方法】回溯 + start 下标。
【要点】
1. 子集问题：每个"回溯树上的节点"本身就是一个答案（区别于排列只在叶子收集）。
2. 用 start 控制只能选当前下标之后的元素，天然保证不重复（{1,2} 与 {2,1} 视为同一子集）。

【复杂度】时间 O(n·2^n)，空间 O(n)。
【易错点】递归传 i+1 而不是 start+1；结果数量是 2^n。

###0017

【要点】

###0039
【方法】回溯 + 排序剪枝。
【要点】
1. 数字可重复选用：递归传入 i 而不是 i+1。
2. 同一层从 start 开始选，保证组合内元素按序，避免 [2,3] 与 [3,2] 重复。

###0022
【方法】回溯 + 括号合法性剪枝。
【要点】

###0079
【方法】网格 DFS 回溯 + 原地标记。
【要点】
1. 从每个格子尝试作为起点；DFS 中向四方向匹配 word 的下一字符。

###0131
【方法】回溯分割 + 回文 DP 预处理。
【要点】

###0051

###0074
【方法】一维化二分。
【要点】
1. 矩阵"行末接行首"整体有序，可直接对 m×n 个元素做二分。
2. 下标换算：row = mid / n，col = mid % n。
【复杂度】时间 O(log(mn))，空间 O(1)。

###0034
【方法】两次 lowerBound。
【要点】
1. 左边界 = 第一个 >= target 的位置（lowerBound）。
2. 检查该位置是否真的是 target；右边界 = lowerBound(target+1) - 1（第一个大于 target 的前一个）。
3. lowerBound 模板：半开区间 [left, right)，nums[mid] >= target 时 right=mid，否则 left=mid+1。
【复杂度】时间 O(log n)，空间 O(1)。
【易错点】target 不存在时返回 {-1,-1}；右边界计算要减一。

###0033
【方法】旋转数组二分（判断哪半有序）。
【要点】
1. mid 切开后，至少一半是有序的：nums[left] <= nums[mid] 则左半有序。
2. 在有序的那半里判断 target 是否落在其值域内：落在则收缩到该半，否则去另一半。
3. 值域判断用闭开区间：左半 [nums[left], nums[mid])，右半 (nums[mid], nums[right]]。
【复杂度】时间 O(log n)，空间 O(1)。
【易错点】判断左半有序用 <=（两点重合也算有序）；两处值域判断的等号位置。

###0153
【方法】二分收缩到最小值。
【要点】
1. 与右端点比较：nums[mid] > nums[right] 说明最小值在 mid 右侧（旋转点在右）；否则在 mid 左侧（含 mid）。
2. 循环条件 left < right，结束时 left==right 即最小值位置。
3. 与"和 target 比"的做法不同：本题与 right 端点比，才能正确处理完全未旋转的情况。
【复杂度】时间 O(log n)，空间 O(1)。
【易错点】else 分支 right = mid（不是 mid-1，mid 可能就是答案）。

###0004
【方法】中位数分割线二分。
【要点】
1. 中位数把合并后数组分成等长的左右两半：在短数组上枚举其贡献 i 个，长数组自动贡献 k-i 个。
2. 合法分割条件：左半的最大值 ≤ 右半的最小值（交叉比较四条边界）。
3. 边界用 ±∞ 处理 i=0、i=m 等极端情形。
4. 总数为奇数取左半最大；偶数取左右两半均值。
【复杂度】时间 O(log(min(m,n)))，空间 O(1)。
【易错点】leftHalf = (m+n+1)/2 兼顾奇偶；比较方向决定 lo/hi 的移动。

###0020

【要点】

###0155
【方法】辅助栈 / 差值法。
【要点】
1. 直观版：辅助栈与主栈同步 push/pop，辅助栈顶永远是当前最小值，getMin O(1)。

【复杂度】全操作 O(1)。

###0739

###0084
【方法】单调递增栈 + 哨兵。
【要点】
1. 以柱 i 为高的最大矩形，宽度 = 右侧第一个更矮柱 与 左侧第一个更矮柱 之间的距离。

###0215
【方法】快速选择（partition 缩域）。
【要点】
1. 全排序 O(n log n) 浪费了"只要第 k 个"的信息。

###0347

###0198

###0279

###0322
【方法】完全背包最少硬币数。
【要点】
1. f(a) = 凑出金额 a 的最少硬币数；f(0)=0，其余初始化为无穷（本题用 amount+1）。
2. 转移 f(a) = min(f(a-coin) + 1) 对每种 coin。
3. 结果 > amount 表示无解，返回 -1。
【复杂度】时间 O(amount×k)，空间 O(amount)。
【易错点】coin <= a 才能转移；与"组合数"题的遍历顺序区别（求最少个数内外层可互换，求组合数不可）。

###0139
【方法】DP 拆分判定。
【要点】
1. f(i) = s[0..i) 能否由字典拼出；f(0)=true（空串）。
2. 枚举最后一个单词的起点 j：f(i) = f(j) && s[j..i) ∈ dict。
3. 字典放 HashSet，子串判断 O(子串长)。
【复杂度】时间 O(n²)（含子串哈希），空间 O(n)。
【易错点】内层枚举 j 是单词起点；找到任一可行 j 即 break。

###0300
【方法】DP（或贪心+二分）。
【要点】
1. f(i) = 以 nums[i] 结尾的 LIS 长度；f(i) = max(f(j)+1)，j<i 且 nums[j]<nums[i]。
2. 答案是 max(f)，不是 f(n-1)（最长子序列未必以最后一个元素结尾）。
3. 进阶 O(n log n)：tails[i] = 长度 i+1 的递增子序列的最小尾元素，二分查找替换位置。
【复杂度】时间 O(n²) / O(n log n)，空间 O(n)。
【易错点】严格递增要求 nums[j] < nums[i]，等号不成立。

###0152
【方法】同时维护最大/最小乘积。
【要点】
1. 负数会让"当前最小"翻身成"最大"，所以以 i 结尾的最大、最小乘积都要维护。
2. 每步三选一：另起一段 x、接最大 fmax*x、接最小 fmin*x。
3. 答案是所有 fmax 的最大值。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】更新 fmax 前要用旧的 fmax/fmin 算 fmin，先用临时变量存候选值。

###0416
【方法】01 背包可行性（子集和）。
【要点】
1. 总和为奇数直接 false；否则问题变成"能否选出子集和为 sum/2"。
2. f(t) = 能否凑出和 t；每个数只用一次，t 必须从大到小遍历（正序会变成完全背包，数字被重复使用）。
3. f(0)=true；凑出 target 即 true。
【复杂度】时间 O(n·target)，空间 O(target)。
【易错点】内层倒序是 01 背包的灵魂；可加 dp[target] 提前返回。

###0032
【方法】栈存"最后未匹配下标"。
【要点】
1. 栈底永远保持"当前有效段之前的那个未匹配位置"作为参照（初始 -1）。
2. '('：下标入栈。')'：弹栈；若栈空，当前 i 成为新参照；否则有效长度 = i - 栈顶。
3. 为什么不用 DP：栈法一次遍历天然处理嵌套与拼接（"()(()" 型）。
【复杂度】时间 O(n)，空间 O(n)。
【易错点】初始哨兵 -1 必须放；弹出后栈空的分支是"重置参照"而不是结算。

###0062
【方法】路径数 DP（组合数）。
【要点】
1. f(i,j) = f(i-1,j) + f(i,j-1)；第一行/列为 1。
2. 一维滚动：dp[j] += dp[j-1]，dp[j] 旧值即"上方"，dp[j-1] 新值即"左方"。
3. 数学法：答案 = C(m+n-2, m-1)，可避免循环。
【复杂度】时间 O(mn)，空间 O(n)。
【易错点】滚动数组初值全 1（第一行）；注意题目 m 行 n 列的对应关系。

###0064
【方法】网格最小路径 DP。
【要点】
1. f(i,j) = grid[i][j] + min(f(i-1,j), f(i,j-1))。
2. 第一行只能从左累加，第一列只能从上累加。
3. 一维滚动数组：逐行覆盖更新。
【复杂度】时间 O(mn)，空间 O(n)。
【易错点】每行开始先更新 dp[0]（加当前行第一列的值）。

###1143
【方法】LCS 二维 DP。
【要点】
1. 尾字符相等：f(i,j) = f(i-1,j-1) + 1；否则 f(i,j) = max(f(i-1,j), f(i,j-1))。
2. 与"最长公共子串"的区别：不匹配时不重置，继承两侧最优。
3. 空间可用两行滚动。
【复杂度】时间 O(mn)，空间 O(n)。
【易错点】字符串下标 i-1、j-1 对应 DP 下标 i、j（f 的 0 表示空串）。

###0072
【方法】编辑距离二维 DP。
【要点】
1. 尾字符相等：f(i,j) = f(i-1,j-1)；否则三种操作取最小 +1：替换 f(i-1,j-1)、删除 f(i-1,j)、插入 f(i,j-1)。
2. 边界：f(i,0)=i（全删），f(0,j)=j（全插）。
【复杂度】时间 O(mn)，空间 O(n)（两行滚动）。
【易错点】插入与删除的方向对应关系别背反——画 2×2 表格验证一遍最稳妥。

###0005
【方法】中心扩展。
【要点】
1. 枚举 2n-1 个中心：单字符（奇长）与字符间隙（偶长）。
2. 每个中心向两侧扩展到不匹配，长度 = right-left-1（退出时多走了一步）。
3. 由中心与长度反推起点 start = i - (len-1)/2。
4. Manacher 可到 O(n)，面试通常中心扩展即可。
【复杂度】时间 O(n²)，空间 O(1)。
【易错点】奇偶两种中心的 expand 参数；起点计算里的 (len-1)/2。

###0136
【方法】异或。
【要点】
1. 异或性质：a^a=0、a^0=a、交换结合律成立。
2. 全体异或，成对数抵消，剩下唯一出现一次的数。
3. 若出现次数是"其余三次、唯一一次"，需要用位计数 %3 的进阶技巧（137 题）。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】初始化 result=0（0 异或任何数不变）。

###0169
【方法】Boyer-Moore 投票。
【要点】
1. 候选者票数 +1，异见者 -1，归零换候选。
2. 多数元素 > n/2，其余元素总数都抵不完它，最终存活者即多数元素。
3. 前提"多数元素一定存在"很关键（否则需二次验证）。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】count==0 时立即换候选再计数。

###0075
【方法】荷兰国旗三指针。
【要点】
1. 不变式：[0,zero) 全 0，(two, n-1] 全 2，[zero, cur) 全 1。
2. cur 遇 0：与 zero 交换，zero++、cur++（换来的必是 1，来自已检查区）。
3. cur 遇 2：与 two 交换，two--，cur 不动（换来的来自未检查区）。
4. cur > two 时结束。
【复杂度】时间 O(n)（一趟），空间 O(1)。
【易错点】遇 2 后 cur 不前进是最关键的一点；循环条件 cur <= two。

###0031
【方法】字典序标准算法。
【要点】
1. 从右找第一个 nums[i] < nums[i+1] 的 i（右侧此时是降序）。
2. 从右找第一个 > nums[i] 的 j（右侧降序，最右的一定是第一个更大的），交换 i、j。
3. 反转 i+1 到末尾：让尾部（仍降序）变成升序最小。
4. i < 0 说明整体降序，直接反转全部。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】步骤 2 找的是"大于 nums[i] 的最小者"，降序序列中从右往左第一个即是。

###0287
【方法】Floyd 判圈（数组当链表）。
【要点】
1. 建映射 i → nums[i]：从 0 出发必然进入环，且环入口就是重复数字（两个不同下标指向同一值）。
2. 阶段一：slow=nums[slow] 一步，fast=nums[nums[fast]] 两步，直到相遇。
3. 阶段二：slow 回起点，同速前进，再次相遇即入环口。
4. 不修改数组、O(1) 空间，是本题唯一同时满足两个约束的经典解法。
【复杂度】时间 O(n)，空间 O(1)。
【易错点】fast 初始化为 nums[nums[0]]（或都从 0 出发但先走再比），步进是"跳两次 nums"；阶段二从 0 而不是 nums[0] 出发。
