# 力扣热题 100 · 安卓刷题应用

一个**完全离线**的 Android 刷题应用，收录 [力扣「热题 100」](https://leetcode.cn/studyplan/top-100-liked/) 全部 100 道经典题目，并为每道题提供 **C / Python3 / Java 三种语言**的参考答案与中文思路解析。

- 界面语言：中文
- 体积：约 5.5 MB，无需联网，**不申请任何权限**
- 题解总量：100 题 × 3 语言 = 300 份代码 + 100 份解析

## 功能特性

- **分类浏览**：按官方专题分组（哈希、双指针、滑动窗口、子串、数组、矩阵、链表、二叉树、图论、回溯、二分查找、栈、堆、贪心算法、动态规划、多维动态规划、技巧），每题带难度标签（简单 / 中等 / 困难 三色区分）
- **题目描述**：题意、示例、数据范围，随时随地复习
- **三语言参考答案**：答案默认隐藏（点击「查看答案」展开），可在 **C / Python3 / Java** 之间一键切换；代码区为深色等宽字体，支持长按选中复制
- **思路解析**：每题包含解题方法、关键要点、易错点和时间/空间复杂度分析
- **纯离线**：所有数据打包在 APK 内，没有网络权限，上课、通勤、飞行模式都能刷

## 安装

方式一：直接安装已构建好的 APK（`app-debug.apk`），拷贝到手机点击安装，允许"未知来源"即可（Android 8.0+）。

方式二：参照下文自行构建。

## 技术实现

| 项目 | 说明 |
|---|---|
| 语言 | Java（无 Kotlin 依赖，构建链简单） |
| UI | XML 布局 + Material Components（AppCompat、RecyclerView） |
| SDK | minSdk 26 / targetSdk 34 / compileSdk 34 |
| 构建 | Gradle 8.7 + Android Gradle Plugin 8.5.2 |
| 数据 | 纯文本资源文件（assets），启动时一次解析，无数据库 |

**数据文件格式**：所有题目内容放在 `app/src/main/assets/`，以 `###题号` 作为分段标记的纯文本文件，改题不用动任何代码：

```
assets/
├── index.json            # 分类与题目元信息（题号、标题、难度）
├── desc1/2.txt           # 题目描述
├── code1~5.txt           # Java 题解
├── code_c1~5.txt         # C 题解
├── code_py1~5.txt        # Python3 题解
└── explain1/2.txt        # 思路解析
```

分段示例（`code_c1.txt`）：

```
###0001
// 思路：C 没有内置哈希表，这里手写一个开放寻址哈希表……
int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    ...
}
```

## 本地构建

环境要求：JDK 17+、Android SDK（platforms;android-34、build-tools;34.0.0、platform-tools）。

```bash
# 命令行构建（需本机安装 Gradle 8.7+，或使用 Android Studio 直接打开）
gradle assembleDebug

# 产物
app/build/outputs/apk/debug/app-debug.apk
```

也可以用 Android Studio 打开本工程，一键 Run 到真机/模拟器（SDK 路径不匹配时在 `local.properties` 中修改 `sdk.dir`）。

## 修改 / 新增题目

1. 编辑 `app/src/main/assets/` 下对应的文本文件，按 `###题号` 追加或修改分段；
2. 在 `index.json` 中登记题目元信息；
3. `gradle assembleDebug` 重新打包即可。
